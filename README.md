# Portfolio Website

A lightweight static academic/technical portfolio. No build tools are required.

## Preview locally

Open `index.html` directly in your browser.

## Replace these placeholders first

Search the files for:

- `Your Name`
- `USERNAME`
- `your.email@example.com`

Also review the presentation/project descriptions and change anything that is not yet public or confirmed.

## Publish with GitHub Pages

1. Create a new GitHub repository, e.g. `portfolio`.
2. Upload all files in this folder to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder.
6. Save. GitHub will show the public URL after deployment.

If you create a repository named `YOUR_GITHUB_USERNAME.github.io`, the site can be published at the corresponding GitHub Pages user-site URL.

## Files

- `index.html` — main homepage
- `cv.html` — printable HTML CV
- `styles.css` — design and responsive layout
- `script.js` — mobile navigation and footer year
